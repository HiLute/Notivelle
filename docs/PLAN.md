# md-editor — план MVP

Согласован 2026-10-12.

## Цель

Редактор Markdown в духе Obsidian, но для **отдельных файлов**, без vault.

MVP одной фразой: md-editor стоит приложением по умолчанию для `.md`. Дабл-клик по файлу
открывает его вкладкой в уже запущенном окне, где его можно править в Live Preview с
callouts, формулами и диаграммами, переключаться в Reading или Source и сохранять, не
боясь испортить файл.

## Стек и принципы

- **Tauri 2** (стабильная ветка 2.x, не 3.0-alpha) + **CodeMirror 6** + **TypeScript** (vanilla, без фреймворка) + Vite, npm.
- Платформы: в MVP только **Linux**. Код с самого начала кроссплатформенный (пути, CRLF);
  сборки под Windows и macOS будут следующим шагом (GitHub Actions).
- **Основная логика на Rust**, и Rust-код полноценный, а не минимальный: проект ещё и
  для изучения языка.
- **У JS нет прямого доступа к файловой системе.** Весь ввод-вывод идёт через наши
  Rust-команды; fs-плагин Tauri фронтенду не выдаём.
- Файлы сохраняются **байт-в-байт**: никакого переформатирования; переводы строк, BOM и
  финальный перевод строки остаются как были.
- Всё работает офлайн: шрифты, KaTeX и Mermaid лежат внутри приложения, CDN нет.

## Что входит в MVP

### Файлы
- Открыть файл можно аргументом командной строки, через Ctrl+O или перетащив его в окно.
- Single instance: повторный запуск открывает файл вкладкой в уже запущенном окне (как Kate).
- Приложение регистрируется для `text/markdown` через `.desktop`-файл.
- Сохранение байт-в-байт: LF/CRLF, BOM, финальный перевод строки. Запись атомарная
  (временный файл, затем rename), права и симлинки сохраняются.
- Watcher: если файл изменили снаружи, чистая вкладка перезагружается сама, а на вкладке
  с правками появляется плашка «файл изменён на диске».

### Вкладки
- Таб-бар с пометкой несохранённых изменений, Ctrl+Tab и Ctrl+W, при закрытии вопрос «сохранить?».
- Если файл уже открыт, повторное открытие переключает на его вкладку.

### Режимы (свой у каждой вкладки, по умолчанию из настроек)
- **Source:** CM6 с подсветкой Markdown и кода в блоках.
- **Live Preview:** разметка скрыта везде, кроме элемента под курсором. Поддерживаются
  заголовки, жирный, курсив, зачёркнутый, inline code, ссылки, списки с кликабельными
  чекбоксами, цитаты, callouts, блоки кода, hr, локальные картинки, формулы, диаграммы.
- **Reading:** HTML, который рендерит Rust.
- Ctrl+E переключает Reading и редактирование; для Source ↔ Live Preview отдельный хоткей.

### Callouts
`> [!type] Заголовок`, сворачивание через `+`/`-`, все стандартные типы Obsidian с
алиасами. Неизвестный тип показывается как `note`.

### KaTeX
- `$...$` для формул в строке, `$$...$$` для отдельного блока.
- Reading: comrak (`math_dollars`) только помечает формулы, а рисует их KaTeX во
  фронтенде. Одна библиотека в обоих режимах, поэтому формулы выглядят одинаково.
- Live Preview: своё расширение парсера lezer для `$`/`$$`, отрендеренная формула как
  виджет, при курсоре внутри виден исходник. Блочные формулы через `StateField`.

### Mermaid
- Блоки ```` ```mermaid ```` превращаются в SVG и в Reading, и в Live Preview.
- Библиотека подгружается только когда в документе есть диаграмма.
- SVG кешируется по хешу текста диаграммы; перерисовка при смене темы.
- `securityLevel: 'strict'`.

### Проверка орфографии
- Своя, на Rust, через крейт `spellbook` (совместим с форматом Hunspell).
- Словари ru_RU и en_US лежат внутри приложения.
- Язык выбирается для каждого слова по алфавиту: кириллица — ru, латиница — en.
- Проверяются только видимые слова вне кода, ссылок, формул и frontmatter.
- Наше контекстное меню: варианты исправления и «добавить в словарь». Личный словарь
  хранится в каталоге конфигурации.

### Прочее
Поиск и замена (Ctrl+F), Vim mode в настройках, светлая и тёмная тема (по умолчанию
как в системе), конфиг в TOML плюс простая панель настроек.

## Что сознательно не входит

Wikilinks, таблицы как виджеты в Live Preview (в Reading рендерятся, в LP остаются
исходником), outline/TOC, восстановление сессии, недавние файлы, экспорт в HTML/PDF,
кодировки кроме UTF-8, несколько окон, установщики для Windows и macOS.

## Архитектура

### Rust (`src-tauri/src/`)

| Модуль | Что делает |
|---|---|
| `document` ✅ | Проверяет UTF-8, определяет BOM и тип переводов строк, восстанавливает их при сохранении |
| `disk` ✅ | Атомарная запись (`tempfile` + `fsync` + rename), права, симлинки, лимит размера 32 МиБ |
| `documents` ✅ | Реестр открытых документов: фронтенд знает только `DocumentId`, путей не передаёт; проверка, не изменился ли файл на диске перед сохранением |
| `dialogs` ✅ | Системные диалоги из Rust: открытие файла, «Сохранить изменения?», «Файл изменился на диске» |
| `startup` ✅ | Файлы из командной строки; фронтенд забирает их, когда готов |
| `watcher` | `notify` с debounce, отсеивает события от наших сохранений, шлёт события во фронтенд |
| `render` | `comrak` (GFM + `math_dollars`), в AST превращает blockquote в callout, санитайзинг через `ammonia` |
| `assets` | Свой URI-протокол для локальных картинок по относительным путям |
| `callouts` | Единый реестр типов, алиасов и иконок для рендера и фронтенда |
| `spellcheck` | `spellbook`, загрузка словарей в фоне, выбор языка по алфавиту, кеш, личный словарь |
| `config` | TOML через `serde`, XDG-пути |
| `error` ✅ | Общий `AppError` через `thiserror`, во фронтенд уходит как `{ kind, message }` |
| `commands` ✅ | Tauri-команды; дисковые операции и диалоги — в отдельном потоке (`spawn_blocking`) |

### TypeScript (`src/`)

Настройка CM6, плагин Live Preview (декорации поверх дерева lezer), виджеты callouts,
формул и диаграмм, плагин проверки орфографии, менеджер вкладок (один `EditorView`
и отдельный `EditorState` на вкладку), отображение Reading, диалоги, хоткеи.

### Порядок рендера в Reading
Markdown → comrak (AST, callouts) → HTML → ammonia → DOM → KaTeX для формул и
Mermaid для диаграмм (они рисуют уже после санитайзинга, в строгом режиме).

## Риски и компромиссы

- **Два парсера:** Live Preview парсит через lezer (JS), Reading через comrak (Rust). На
  редких конструкциях результат может немного различаться. В Obsidian так же.
- **CSP:** Mermaid вставляет `<style>` внутрь SVG, поэтому `style-src` разрешает
  `'unsafe-inline'`, а подстановка nonce в `style-src` отключена
  (`dangerousDisableAssetCspModification`). Скрипты остаются под nonce.
- **WebKitGTK + NVIDIA** (на машине гибридная графика Intel + RTX 3060): подтвердилось на
  M0 — `Error 71 (Protocol error) dispatching to Wayland display`. Решено в
  `src-tauri/src/main.rs`: на Linux первой строкой `main` выставляется
  `WEBKIT_DISABLE_DMABUF_RENDERER=1`, если пользователь не задал её сам. Это единственный
  `unsafe` в проекте (`set_var` в edition 2024), с обоснованием `// SAFETY:`.
- **M4** — самый объёмный этап: Live Preview с виджетами формул и диаграмм.
- **Смешанные переводы строк** (CRLF и LF в одном файле) байт-в-байт не сохранить:
  редактор хранит строки с `\n`. При сохранении все переводы приводятся к самому частому
  виду; строка состояния предупреждает об этом при открытии. Сохранение без правок файл
  не трогает.
- **Атомарное сохранение** заменяет файл новым: жёсткие ссылки на него и расширенные
  атрибуты (xattr, ACL) не сохраняются. Права и симлинки сохраняются.
