# Добро пожаловать в md-editor

Откройте Markdown-файлы: **Ctrl+O**, перетащите их в окно или запустите
`md-editor файл.md` — если программа уже открыта, файлы появятся вкладками в ней.
Сохранить: **Ctrl+S**. Файл сохранится байт-в-байт: переводы строк (LF/CRLF)
и BOM останутся такими же, как были.

## Что уже работает

- вкладки: **Ctrl+Tab** / **Ctrl+Shift+Tab** (или Ctrl+PgDn / Ctrl+PgUp) — соседняя,
  **Ctrl+W** — закрыть; у каждой вкладки своя история отмены
- подсветка *курсива*, **жирного**, ~~зачёркнутого~~ и `inline code`
- [ссылки](https://tauri.app) и списки: Enter продолжает список
- отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), поиск и замена (Ctrl+F)
- вопрос о несохранённых изменениях при закрытии вкладки и окна
- защита от перезаписи файла, который изменила другая программа

- [ ] чекбоксы задач
- [x] подсветка кода внутри блоков

> [!note] Callouts
> Пока это обычная цитата. Как в Obsidian она будет выглядеть с этапа M3.

```rust
fn main() {
    let greeting = "Привет из блока кода";
    println!("{greeting}");
}
```

Формулы вроде $E = mc^2$ и диаграммы Mermaid появятся на этапах M3–M4.
