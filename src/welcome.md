# Добро пожаловать в md-editor

Откройте Markdown-файлы: **Ctrl+O**, перетащите их в окно или запустите
`md-editor файл.md` — если программа уже открыта, файлы появятся вкладками в ней.
Сохранить: **Ctrl+S**. Файл сохранится байт-в-байт: переводы строк (LF/CRLF)
и BOM останутся такими же, как были.

## Что уже работает

- вкладки: **Ctrl+Tab** / **Ctrl+Shift+Tab** (или Ctrl+PgDn / Ctrl+PgUp) — соседняя,
  **Ctrl+W** — закрыть; у каждой вкладки своя история отмены
- три режима, как в Obsidian: **Live Preview** (разметка видна только под курсором),
  **Исходник** и **Чтение**. Переключаются кнопками в строке состояния справа,
  **Ctrl+E** — чтение, **Ctrl+Shift+E** — исходник ⇄ Live Preview
- в Live Preview: Ctrl+клик открывает ссылку, клик по чекбоксу отмечает задачу
  (в режиме чтения тоже), клик по callout или диаграмме открывает её исходный текст.
  Стрелки вверх и вниз заходят в такие блоки, а не перепрыгивают их
- таблицы правятся прямо на месте: клик по ячейке, **Tab** — следующая ячейка,
  **Enter** — ячейка ниже (в последней строке — новая строка). Кнопки «+» справа и
  снизу добавляют столбец и строку, ручки слева и сверху открывают меню и
  перетаскивают строки и столбцы, правый клик — меню таблицы
- подсветка *курсива*, **жирного**, ~~зачёркнутого~~, ==выделенного== и `inline code`,
  HTML вроде <kbd>Ctrl</kbd>+<kbd>S</kbd> и H<sub>2</sub>O
- [ссылки](https://tauri.app) и списки: Enter продолжает список
- отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), поиск и замена (Ctrl+F)
- вопрос о несохранённых изменениях при закрытии вкладки и окна
- защита от перезаписи файла, который изменила другая программа

- [ ] чекбоксы задач
- [x] подсветка кода внутри блоков

| Режим        | Разметка          | Клавиши      |
|--------------|-------------------|--------------|
| Live Preview | под курсором      | Ctrl+Shift+E |
| Исходник     | видна вся         | Ctrl+Shift+E |
| Чтение       | не видна          | Ctrl+E       |

> [!tip] Callouts
> Цитата с маркером `[!тип]` выглядит как в Obsidian. Клик по ней открывает исходный текст.

```rust
fn main() {
    let greeting = "Привет из блока кода";
    println!("{greeting}");
}
```

Формулы вроде $E = mc^2$ рисуются прямо в тексте, а блоки ```` ```mermaid ```` — диаграммами.
