# Добро пожаловать в md-editor

Это **каркас** (этап M0): пока здесь только редактор CodeMirror 6 с подсветкой Markdown.
Открытие и сохранение файлов появятся на этапе M1.

## Что уже работает

- подсветка *курсива*, **жирного**, ~~зачёркнутого~~ и `inline code`
- [ссылки](https://tauri.app) и списки: Enter продолжает список
- отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), поиск и замена (Ctrl+F)

- [ ] чекбоксы задач
- [x] подсветка кода внутри блоков

> [!note] Callouts
> Пока это обычная цитата. Как в Obsidian она будет выглядеть с этапа M3.

```rust
fn main() {
    let greeting = "Привет из блока кода";
    println!("{greeting}");
}
```

Формулы вроде $E = mc^2$ и диаграммы Mermaid появятся на этапах M3–M4.
